# Unpublished assets (moved here 2026-11-15, audit item SB27-13)

No page, stylesheet, script or data file referenced these 24 files, so they were being served for nothing.
Folders that start with "_" are not published by GitHub Pages (Jekyll skips them), so they stay in the repo
but leave the live site.

- `gal-1..12.jpg`: full-size originals of the gallery photos. The site uses `img/gal-1..12.webp`.
- `hero-band.jpg`: the 1880x940 Eventbrite hero built from the flyer art (an upload source, not a web asset).
- `band-2.jpg`, `poster-*.jpg`, `img/band-2.webp`, `img/hero-band.webp`, `img/poster-*.webp`: the poster row removed 2026-09-22 and older banner art.

To use one on a page again, move it back into `img/` (as WebP at display size) and reference it.
